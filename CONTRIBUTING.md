# Contributing to STM32 PWM RGB LED Console

## 🎓 **Welcome Students and Learners!**

This project is designed as a **learning resource** for embedded systems development. Whether you're a student, hobbyist, or professional, your contributions are welcome!

## 🎯 **Project Goals**

- **Educational**: Demonstrate real-world embedded systems practices
- **Practical**: Provide working examples of STM32, FreeRTOS, and sensor integration
- **Community**: Share knowledge and help others learn

## 🚀 **How to Contribute**

### **For Students**
1. **Try the project**: Build, flash, and experiment with the code
2. **Ask questions**: Open issues for anything you don't understand
3. **Share improvements**: Submit pull requests for bug fixes or enhancements
4. **Document**: Help improve documentation or add comments

### **For Educators**
1. **Use in classes**: Feel free to use this project in your embedded systems courses
2. **Suggest improvements**: Help make it more educational
3. **Share feedback**: Let us know how students respond to it

### **For Developers**
1. **Code improvements**: Optimize performance, add features
2. **Bug fixes**: Help maintain code quality
3. **Documentation**: Improve README, add code comments

## 📝 **Contribution Guidelines**

### **Before Submitting**
- Test your changes thoroughly
- Follow the existing code style
- Update documentation if needed
- Add comments explaining complex logic

### **Pull Request Process**
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/amazing-feature`
3. Commit your changes: `git commit -m 'Add amazing feature'`
4. Push to the branch: `git push origin feature/amazing-feature`
5. Open a Pull Request

### **Code Style**
- Use clear, descriptive variable names
- Add comments for complex algorithms
- Follow C coding standards
- Include error handling
